# Maryam Shehu Muhammad — UI/UX Portfolio

A complete Next.js portfolio containing nine independent product-design explorations: Hirewise, MAHLI, SiteCheck, Nara, Roam, Gona, Nadi, Morrow and TOLD.

Hirewise, SiteCheck, Nara, Gona and Nadi each include a complete, responsive public landing page inside the case study. Morrow is a complete charity landing page from navigation to footer. TOLD is a deeper oral-history case study with problem framing, goals, process, landscape review, product screens and a fully broken-down marketing site.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Push this folder to GitHub and import the repository into Vercel. Vercel will detect Next.js automatically; no environment variables or additional settings are needed.
